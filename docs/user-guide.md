# Mason Markdown 用户指南

## 使用前检查

- Halo 版本为 `2.25.0` 或更高版本。
- 插件已经启用。
- 独立 UC 编辑页的账号拥有 `uc:posts:manage`。
- 需要发布或取消发布文章时，账号还需要 `uc:posts:publish`。

## 选择编辑器

在 Halo Console 的文章新建或编辑页面打开编辑器切换菜单，选择 **Mason Markdown**。已有文章的原始 Markdown 内容会通过 Halo 的标准 `raw/content` 契约交给编辑器处理。

## 使用独立 UC 编辑页

独立页面路由为：

```text
/uc/masonmd-editor
```

页面负责文章标题、分类、标签、封面、可见性、置顶、正文保存和发布。分类和标签来自 Halo 的内容 API，不需要在主题中维护另一份数据。

### 保存和自动保存

- 新文章首次保存后才会创建服务器端草稿。
- 自动保存默认间隔为五分钟。
- 页面会显示最近的自动保存记录，并允许查看 Markdown 源码快照。
- 离开页面时若仍有未保存修改，浏览器会显示默认离开确认；页面不会擅自替用户保存。
- 保存冲突会尝试重新读取服务器版本并保留当前编辑内容，失败时需要手动重试。

### 发布状态

文章状态由 Halo UC API 的公开/私有状态决定：

- `PUBLIC`：公开文章，且需要发布权限才能发布。
- `PRIVATE`：私有文章，保存时会同步取消发布状态。

发布成功后页面会显示查看文章入口。删除文章使用 Halo 的回收接口，确认后会根据来源页面返回；非法或 404 来源会回到首页。

## 附件、分类和标签

- 封面可以填写地址、从 Halo 附件库选择，或上传本地文件。
- 图片插入和封面上传使用 Halo UC 附件接口。
- 分类来自 Halo 后台分类数据，支持层级分类展示。
- 标签选择器读取 Halo 后台已有标签，选择结果写入文章的 `spec.tags`。

## Markdown 和文章页

Mason Markdown 编辑器预览与文章页共享 `mason-v1` Markdown 管线。`mason-v1` 是历史兼容配置标识，不是用户界面品牌。语法范围和边界以 [全语法测试文档](./compatibility/mason-markdown-all-syntax-test.md) 为准。文章页所需 CSS、KaTeX 样式和 Mermaid 布局脚本由插件随 JAR 发布，不需要复制到主题中。

公式、Mermaid、表格和代码块出现差异时，请先阅读 [排错指南](./troubleshooting.md)，并确认问题属于编辑器预览还是文章页。
